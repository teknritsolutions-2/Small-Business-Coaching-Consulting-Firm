# Installation Guide

Northline Advisory is a static HTML, CSS, and JavaScript template. It does not require a build step.

## Run Locally

Open `index.html` in a browser, or serve the folder with any static server.

Example:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

Upload the full project folder to any static host. Keep the root files, `assets/`, `pages/`, and `documentation/` together so relative links continue to resolve.
