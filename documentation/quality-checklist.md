# Quality Checklist

- CSS is grouped in `assets/css/`.
- JavaScript is grouped in `assets/js/`.
- Page HTML is grouped in `pages/`.
- Image files are stored directly in `assets/images/`.
- Development-only dashboard test pages are not included in the delivered page set.
- Placeholder image SVGs and macOS metadata files are not included.
- `index.html` remains at the project root to redirect static hosting traffic to `pages/index.html`.
