# Page Structure

The template follows the requested static layout:

```text
assets/
  css/
    style.css
    dark-mode.css
    rtl.css
  js/
    main.js
    dashboard.js
    plugins/
  images/
  fonts/
pages/
documentation/
README.md
```

## Dashboard Pages

Dashboard files live under `pages/dashboard/`, with admin pages under `pages/dashboard/admin/`.

## Asset Notes

Images are stored directly in `assets/images/`. Page-specific image subfolders are intentionally not used.
